Capstone · System architecture · v2

Constructive News AI

Agents collect credible news, keep only stories that show real progress, and file them as scored, de-duplicated stories. Each morning a briefing is built for every user. At any time, users can explore stories or ask the RAG chat, which answers only from stored stories and cites them.

What changed from v1

  • Tech, Finance and Politics agents are replaced by fetchers split by source type. The 8 pillars are assigned later, by classification.
  • A new constructive scoring agent applies the 7 weighted dimensions. The weights live in a config file, so editors can change them without code changes.
  • Duplicates are clustered into one story marked “reported by N sources”. Before, extra copies were deleted.
  • A new briefing lane with per-user personalisation, diversity rules, briefing length, caching and push notifications.
  • A user store for logins, preferences and feedback, which personalisation needs.
  • A chunk index of full article text (300–500 tokens per passage), kept for 30 days for detailed questions in the chat.

Where RAG fits now

The chat searches in two steps. Step 2 finds the right stories using scores, pillars and verification level, so rejected articles never come up. Step 3 then finds the best passages from the full text of only those stories, which answers detail questions like “how does it work?” or “who funded it?”. Full-text chunks are never shown to users, answers paraphrase with at most one short quote, and chunks are deleted after 30 days. Older stories fall back to their summary and key facts.
